# All in Term Homebrew tap

Homebrew cask for [All in Term](https://allinterm.com/), a terminal app with SSH, SFTP and server tools for macOS.

## Install

```bash
brew install --cask muammersahin/tap/all-in-term
```

If Homebrew refuses to load the cask from an untrusted tap, trust the tap first:

```bash
brew trust muammersahin/tap
```

## Update

```bash
brew upgrade --cask all-in-term
```

## Uninstall

```bash
brew uninstall --cask all-in-term
```

Add `--zap` to also remove saved settings.

The app is signed with a Developer ID certificate and notarized by Apple. Builds are available for Apple Silicon and Intel Macs.
